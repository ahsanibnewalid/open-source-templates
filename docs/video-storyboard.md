# Open Source Templates Library — 20-second showcase

This storyboard is a production brief for creating a short repository launch video. It is not a rendered video file.

**Format:** 16:9, 1080p or higher, 20 seconds, crisp UI motion, dark navy / electric blue accents, upbeat but restrained electronic soundtrack, no copyrighted music without permission.

| Time | Visual | On-screen text | Motion / audio |
|---|---|---|---|
| 0–3s | A clean grid of website thumbnails appears | OPEN SOURCE. BUILD FASTER. | Quick fade-in, soft digital pulse |
| 3–6s | Cards group into SaaS, dashboards, e-commerce, and portfolio | TEMPLATES BY CATEGORY | Cards slide into labeled columns |
| 6–10s | Split-screen of React/Next.js and Python/FastAPI code/editor visuals | CHOOSE YOUR STACK | Smooth horizontal pan; subtle keyboard clicks |
| 10–14s | A generic landing page transforms into a branded dashboard | CUSTOMIZE THE DESIGN | Color palette and UI panels morph |
| 14–17s | Checklist icons appear: license, security, tests, deployment | REVIEW. TEST. SHIP. | Four quick, synchronized highlights |
| 17–20s | Repository title and GitHub repository URL | YOUR NEXT PROJECT STARTS HERE | Clean end card; music resolves |

## Suggested production workflow

1. Capture the real repository README and category pages after they are published.
2. Use only screenshots of templates whose demos and licenses you have checked.
3. Create the motion sequence in a video editor or a dedicated video-generation workflow.
4. Keep the final export separate from the source repository unless you intentionally want to store the rendered asset there.
