# CMS, Blogs & Documentation

For content-heavy business websites, editorial blogs, documentation portals, and websites where non-developers need to update content.

| Project | What to explore | Stack / notes |
|---|---|---|
| [Payload CMS](https://github.com/payloadcms/payload) | CMS with a TypeScript/Next.js-oriented approach | Content models, admin UI, access control |
| [Strapi](https://github.com/strapi/strapi) | Headless CMS and content APIs | Node.js ecosystem; inspect edition and license |
| [Astro](https://github.com/withastro/astro) | Content-first website framework | Supports static and server-rendered sites |
| [Docusaurus](https://github.com/facebook/docusaurus) | Documentation websites | React-based docs, versioning and search integrations |
| [Ghost](https://github.com/TryGhost/Ghost) | Publishing and membership platform | Node.js-based publishing; review current license and hosting model |

**Customization ideas:** article layouts, author profiles, categories/tags, search, SEO metadata, localization, preview workflows, and editorial roles.

**Watch out for:** media storage, backups, editor permissions, sanitizing user-submitted content, redirects, and plugin/update compatibility.
