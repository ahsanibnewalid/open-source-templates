# Python: FastAPI & Django

For database-backed websites, REST APIs, internal tools, and Python-based business applications.

| Project | What to explore | Stack / notes |
|---|---|---|
| [Full Stack FastAPI Template](https://github.com/fastapi/full-stack-fastapi-template) | Full-stack API + web app foundation | FastAPI, React, SQLModel, PostgreSQL, Docker |
| [Cookiecutter Django](https://github.com/cookiecutter/cookiecutter-django) | Structured Django project generation | Django and configurable production-oriented services |
| [Django](https://github.com/django/django) | Core framework and official examples | Python web framework; pair with a suitable frontend/theme |
| [FastAPI](https://github.com/fastapi/fastapi) | API foundation and documentation examples | Python type hints, OpenAPI |
| [Django REST Framework](https://github.com/encode/django-rest-framework) | API layer for Django applications | REST APIs, serializers, permissions |

**Customization ideas:** staff portals, inventory systems, appointment platforms, reporting dashboards, and CRUD applications.

**Watch out for:** Django/FastAPI version support, database migrations, secret management, object-level permissions, background jobs, and deployment configuration.
