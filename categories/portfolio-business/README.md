# Portfolio & Business Websites

For developer portfolios, agency websites, company landing pages, and service businesses.

| Project | What to explore | Stack / notes |
|---|---|---|
| [Simplefolio](https://github.com/cobiwave/simplefolio) | Minimal developer portfolio | HTML/SCSS/JavaScript toolchain; check current maintenance |
| [DeveloperFolio](https://github.com/saadpasta/developerFolio) | Configurable developer portfolio | React-based portfolio |
| [Astro](https://github.com/withastro/astro) | Framework for fast content and marketing sites | Use an official or community theme compatible with your version |
| [Start Bootstrap](https://github.com/StartBootstrap) | Collection of Bootstrap site templates | Check each repository's license and included assets |
| [HTML5 UP](https://github.com/ajlkn) | Responsive HTML website themes | Review the specific theme and attribution requirements |

**Customization ideas:** hero, services, case studies, testimonials, team, pricing, contact forms, SEO, analytics, and accessible mobile navigation.

**Tip:** remove demo copy and placeholder contact details before publishing. Verify image, font, icon, and stock-photo usage rights independently of the template's code license.
