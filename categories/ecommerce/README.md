# E-commerce

For storefronts, product catalogs, shopping carts, order management, and commerce backends.

| Project | What to explore | Stack / notes |
|---|---|---|
| [Medusa](https://github.com/medusajs/medusa) | Open commerce backend and integrations | Node.js ecosystem; pair with a compatible storefront |
| [Medusa Next.js Starter](https://github.com/medusajs/nextjs-starter-medusa) | Storefront starter | Next.js; check compatibility with your chosen Medusa version |
| [Saleor](https://github.com/saleor/saleor) | Commerce platform and API | Python/Django ecosystem with GraphQL |
| [Vendure](https://github.com/vendure-ecommerce/vendure) | Customizable commerce platform | TypeScript/Node.js ecosystem |
| [WooCommerce](https://github.com/woocommerce/woocommerce) | WordPress commerce | PHP/WordPress plugin; check extensions and theme licenses individually |

**Customization ideas:** brand colors, product cards, category filters, cart/checkout, order status, inventory, shipping rules, and admin workflows.

**Before accepting real payments:** use a sandbox first, verify webhook signatures and idempotency, protect customer data, and review tax, refund, shipping, and PCI-related responsibilities.
