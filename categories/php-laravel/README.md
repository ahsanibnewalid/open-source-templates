# PHP & Laravel

For business websites, custom web apps, portals, and admin workflows in the PHP ecosystem.

| Project | What to explore | Stack / notes |
|---|---|---|
| [Laravel](https://github.com/laravel/laravel) | Official application starter | PHP framework project skeleton |
| [Filament](https://github.com/filamentphp/filament) | Admin panels, forms, tables, and actions | Laravel/PHP; inspect plugins and compatibility |
| [Livewire](https://github.com/livewire/livewire) | Dynamic interfaces with server-side PHP | Laravel ecosystem |
| [Inertia.js](https://github.com/inertiajs/inertia) | Server-driven app architecture with modern frontend frameworks | Supports multiple frontend adapters |
| [Laravel Breeze](https://github.com/laravel/breeze) | Authentication starter scaffolding | Minimal auth starter; verify compatibility with current Laravel |

**Customization ideas:** customer portals, CRM, booking, inventory, HR workflows, and reporting.

**Watch out for:** supported PHP/Laravel versions, authorization policies, CSRF protection, queue workers, mail delivery, and migration/backup procedures.
