# Full-stack React & Next.js

For TypeScript websites and applications using React-based interfaces, API routes, server components, and database integrations.

| Project | What to explore | Stack / notes |
|---|---|---|
| [Next.js](https://github.com/vercel/next.js) | Official framework and starter examples | React, TypeScript support, App Router |
| [T3 Stack create-t3-app](https://github.com/t3-oss/create-t3-app) | Type-safe app scaffolding | Next.js ecosystem; select only the tools you need |
| [shadcn-admin](https://github.com/satnaing/shadcn-admin) | Admin UI foundation | React, TypeScript, Tailwind/shadcn-style UI; check current project status |
| [Refine](https://github.com/refinedev/refine) | Data-heavy internal tools and admin apps | React framework with multiple backend integrations |
| [Payload](https://github.com/payloadcms/payload) | Full-stack CMS and content-powered apps | TypeScript and Next.js-oriented architecture |

**Customization ideas:** reusable design system, responsive navigation, authentication screens, dashboards, forms, data tables, and API-backed workflows.

**Watch out for:** server/client boundaries, authorization on the server (not just hidden UI), schema validation, caching behavior, and framework-version compatibility.
